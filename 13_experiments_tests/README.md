# 13 — Experiments and Tests

Model experiments, evaluation runs, and their generated outputs
(classification reports, plots, comparison tables).

## Subfolders

| Folder | Purpose |
| --- | --- |
| `clean_experiment/` | Curated end-to-end experiment |
| `classification_results/` | Classification model outputs and plots |
| `integration_experiments/` | Tests on the integrated dataset |
| `pca_experiments/` | PCA / t-SNE results |

## Related

Generated plots are also curated into `20_images/`. Reports are
summarized in `16_reports_results/`.

## Status

This folder documents what was tried and what worked, not just what
succeeded. Failed experiments are preserved alongside successful ones.
