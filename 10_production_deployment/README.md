# 10 — Production Deployment

Deployment-oriented components: the model serialization pipeline, a
prediction service, monitoring hooks, and retraining scaffolding.

## Subfolders

| Folder | Purpose |
| --- | --- |
| `production_core/` | Model serialization and prediction service |
| `live_trading/` | Live trading integration (simulated) |
| `trading_strategies/` | Strategy implementations |

## Status

**Scaffolding only.** No model has been deployed to a live environment.
This folder exists to document the intended production shape, not to
represent an operational system.
